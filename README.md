# A23 基于大语言模型的文档理解与多源数据融合系统

## 项目介绍

本项目是一个基于大语言模型的文档理解与多源数据融合系统，旨在实现从多种格式文档中自动提取信息并填充到指定模板的功能。系统支持处理Word、Excel、Markdown和TXT等多种格式的文档，通过信息抽取和语义匹配技术，实现智能填表。

## 核心功能模块

### 1. 文档解析模块
- 支持Word、Excel、Markdown、TXT等多种格式文档的解析
- 将不同格式的文档转换为统一的JSON结构
- 提取文档中的段落、表格和原始文本

### 2. 信息抽取模块
- 支持基于规则（正则表达式）的信息抽取
- 支持基于NER模型的信息抽取（可选）
- 支持基于大语言模型的信息抽取（可选）
- 支持从文档段落和表格中抽取实体

### 3. 数据结构化模块
- 将抽取的信息进行结构化处理
- 构建知识池存储结构化数据
- 支持跨文档的数据融合

### 4. 字段语义匹配模块
- 基于语义相似度的字段匹配
- 支持模板字段与抽取实体的智能匹配
- 提高自动填表的准确性

### 5. 自动填表模块
- 支持Excel和Word模板的自动填充
- 根据语义匹配结果填充相应字段
- 生成填充后的文档

## 技术栈

### 后端
- Python 3.8+
- FastAPI：Web API框架
- Uvicorn：ASGI服务器
- python-docx：Word文档解析
- pandas/openpyxl：Excel文件处理
- sentence-transformers：语义向量模型
- transformers：命名实体识别（可选）
- openai：大语言模型接口（可选）

### 前端
- 轻量级前端界面（基于HTML）
- 可选：Streamlit或Gradio（如需更复杂的前端交互）

## 使用说明

### 启动服务

```bash
# 进入后端目录
cd backend

# 启动FastAPI服务
python app/main.py
```

服务将在 `http://localhost:8000` 上运行。

### API接口

#### 1. 上传文档并解析抽取实体
- **URL**: `/upload_docs`
- **方法**: POST
- **参数**: 多个文件（支持.docx, .xlsx, .md, .txt格式）
- **返回**: 文档ID列表和成功消息

#### 2. 上传模板并自动填表
- **URL**: `/fill_template`
- **方法**: POST
- **参数**: 模板文件（支持.xlsx, .docx格式）
- **返回**: 填充后的文件

#### 3. 查询指定文档的实体
- **URL**: `/entities`
- **方法**: GET
- **参数**: doc_id（文档ID）
- **返回**: 文档中的实体列表

#### 4. 根路径
- **URL**: `/`
- **方法**: GET
- **返回**: 系统欢迎信息

### 前端使用

打开浏览器访问 `http://localhost:8000`，即可使用前端界面上传文档和模板，进行自动填表操作。

## 技术亮点

1. **多格式文档支持**：支持Word、Excel、Markdown和TXT等多种格式文档的解析
2. **多方法信息抽取**：结合规则、NER模型和大语言模型进行信息抽取
3. **语义匹配**：基于sentence-transformers的语义相似度匹配，提高填表准确性
4. **知识池**：构建知识池存储和管理抽取的实体，支持跨文档数据融合
5. **自动化流程**：从文档上传到自动填表的全流程自动化
